# 한사랑2차 생활정보

한사랑2차삼성아파트 입주민이 외출 전에 날씨와 교통 정보를 확인하고, 단지 안에서 필요한 연락처와 시설 정보를 찾아보는 웹앱입니다.

## 앱에서 볼 수 있는 정보

- **오늘**에서 등촌1동 날씨와 시간대별·일자별 예보, 증미역·등촌역의 다음 열차, 후문·등촌역 버스 도착 정보를 확인합니다. 버스는 정류장별로 가장 빨리 도착하는 다섯 대를 먼저 보여주며, 같은 노선의 다음 도착 시각도 함께 확인할 수 있습니다.
- **도로 전광판**에서 단지 출발 기준으로 마곡나루역, 김포공항 국내선, 여의도역, 홍대입구역까지의 자동차 소요 시간을 확인합니다. 카카오 API를 설정하면 다른 목적지도 검색할 수 있습니다.
- **동네 소식**에서 시간마다 수집한 강서구 행사 달력과 목록을 봅니다. 접수가 끝난 행사는 하단에서 펼쳐 보고, 구청 공지·까치뉴스는 제목으로 검색할 수 있습니다.
- **단지 생활**에서 아파트 공지사항, 전기차 충전소, 관리사무소 정보를 확인합니다. 등록한 편집자 계정으로 `/admin`에 로그인해 사진을 첨부하거나 공지를 게시·수정·삭제할 수 있습니다.

버스는 서울시 정류소 API에서 조회합니다. 공식 조회를 사용할 수 없으면 Makka를 통해 도착 정보를 가져오며, 화면에서 TOPIS도 열 수 있습니다.

## 로컬에서 실행

Node.js 24가 설치된 상태에서 저장소 루트에서 실행합니다.

```sh
npm ci
npm run build
npm start
```

실행 후 [http://127.0.0.1:4189/](http://127.0.0.1:4189/)에서 앱을 엽니다.

화면은 React, TypeScript, Vite로 만들었습니다. 서버 API는 Cloudflare Worker에서 실행하며 ChatGPT Sites에 배포할 수 있습니다.

- [아파트 공지 관리 가이드](ADMIN-GUIDE.md)에서 첫 운영자 등록과 편집자 관리, 사진 공지 게시 방법을 확인합니다.
- [설치·배포 매뉴얼](INSTALL.md)에는 로컬 실행, API 키 설정, Sites 배포 절차가 있습니다.
- [도로 전광판 문서](ROADS.md)에서 교통 데이터 출처를 확인합니다.
